# WBand — Frontend

WBand — веб-приложение для музыкантов, которое помогает организовать бенды, управлять составами, репертуаром и расписанием репетиций.

## Возможности

### Бенды и участники

- **Создание и управление бендами** — создавайте бенды, переименовывайте и удаляйте их.
- **Роли участников** — три роли: `owner`, `admin`, `member`. Владелец может передать владение другому участнику.
- **Приглашения** — владельцы и администраторы приглашают участников по email. Приглашённый получает письмо и может принять или отклонить приглашение.
- **Мои приглашения** — отдельная страница, где пользователь видит все приглашения, отправленные ему, и может принять или отклонить каждое из них.
- **Покинуть бенд** — участник (не владелец) может самостоятельно покинуть бенд.

### Репертуар

- **Песни** — каталог песен с тональностью, BPM, лирикой и аккордами.
- **Сетлисты** — наборы песен для конкретных выступлений или репетиций.

### Календарь

- Расписание репетиций и выступлений с привязкой к бенду.

## Технологии

| Слой            | Стек                                                  |
| --------------- | ----------------------------------------------------- |
| Фреймворк       | React 19, React Router 7                              |
| Язык            | TypeScript 5.9                                        |
| Сборка          | Vite 8                                                |
| Стили           | Tailwind CSS 4, tw-animate-css                        |
| UI-компоненты   | shadcn/ui (Base UI), Lucide Icons                     |
| Авторизация     | Keycloak (через @react-keycloak/web)                  |
| API-клиент      | Генерируется через [Orval](https://orval.dev) из OpenAPI-спецификации Bands Service |
| Линтинг         | ESLint 9, typescript-eslint                           |

## Быстрый старт

```bash
# Установка зависимостей
cd web
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Перегенерация API-клиента из OpenAPI
npm run generate:bands-api
```

## Структура проекта

```
web/
├── src/
│   ├── components/       # UI-компоненты, sidebar, провайдеры
│   ├── lib/
│   │   ├── api/          # API-клиент (generated + custom-fetch)
│   │   ├── bands.ts      # Утилиты форматирования
│   │   └── mock-data.ts  # Моковые данные для песен, сетлистов, календаря

├── orval.config.ts       # Конфигурация генератора API-клиента

```

## Переменные окружения

Приложение подключается к Bands Service по адресу, заданному в `orval.config.ts` (по умолчанию `https://bands-api.staging.wband.ru`). Конфигурация Keycloak задаётся в auth-провайдере.
